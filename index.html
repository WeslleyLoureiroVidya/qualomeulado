Sobre o projeto

O Qual o meu lado? foi criado para ajudar qualquer pessoa a entender melhor o seu posicionamento político através de situações práticas do quotidiano brasileiro. Cada escolha mostra se você tende mais para a esquerda ou para a direita, com uma linguagem simples e directa.

Projeto gerado por Inteligência Artificial. Use o resultado apenas como ponto de partida para refletir, nunca como imposição de voto.
Privacidade total. O site não guarda os seus dados, histórico ou localização. Tudo corre diretamente no seu telemóvel ou computador.
